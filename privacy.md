# Privacy Policy

Mode Shave Cloud Backup is a private utility operated
by Samantha Hill Limited for business backup purposes.

The application uses Google Drive access to transfer,
manage and verify encrypted backup files.

Google user data is used solely for backup and recovery
purposes. It is not sold, shared with advertisers or
used for advertising or AI training.

Access is restricted to authorised operators.
Backup files are encrypted before transfer.
